# Estudos

Projeto de uso pessoal, focado no frontend: um caderno para organizar meus estudos em módulos, com uma identidade visual própria em cada um.

Não tem backend. Os dados ficam só no navegador de cada aparelho, e o app funciona offline como PWA.

## Tecnologias

React, TypeScript, Vite, Tailwind CSS, Dexie (IndexedDB) e vite-plugin-pwa.

## Como rodar

```bash
npm install
npm run dev
```
